# SINNER - Motorcycle Cinematic Portfolio

## Overview

A premium cinematic motorcycle portfolio for Ibrahim Ellaban (@hemaellaban), professional GSX-R1000 rider.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main cinematic portfolio website |
| `generative-art.html` | Interactive motorcycle flow field art |
| `poster.html` | SINNER motorcycle poster |

## Features

- Full-screen video backgrounds
- Cinematic film grain & vignette effects
- Video carousel with smooth transitions
- Scroll-triggered animations
- Responsive design (mobile + desktop)
- Instagram integration

## Assets

```
assets/
├── vid/          # Scene videos (desktop + mobile)
├── img/          # Thumbnail images
└── real_videos/  # Real TikTok content (cinematic enhanced)
```

## Quick Start

1. Open `index.html` in a browser
2. Scroll through the experience
3. Click "VIEW INSTAGRAM" to visit @hemaellaban
